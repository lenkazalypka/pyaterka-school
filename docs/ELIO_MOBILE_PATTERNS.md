# Mobile-паттерны elio

Версия 1.0 · 21 августа 2026

## Базовые ограничения

- поддерживаем ширину от 320 px;
- touch target — не меньше 44×44 px;
- используем `min-height: 100dvh`, когда экран должен занимать viewport;
- критичное действие не зависит от hover;
- текст и кнопки не требуют горизонтального скролла.

## Кабинет ученика

Нижняя навигация содержит только рабочие разделы: сегодня, расписание, уроки. Будущие функции не занимают место в mobile navigation. Контент получает нижний отступ под fixed navigation.

## Сегодня

Порядок на телефоне:

1. дата и приветствие;
2. статус подписки или критическое уведомление;
3. следующее занятие;
4. срочные задания;
5. план дня;
6. цели по предметам.

## Расписание

Событие показывает локальную дату и время, предмет, название и одно основное действие. Кнопка подключения может стать icon-only только с доступным `aria-label`.

## Урок

На мобильном материалы и запись идут до справочной панели целей. Sticky aside отключается. Длинное название переносится без обрезки, а внешние ссылки явно открываются в новой вкладке.

## Формы

Один столбец, видимые labels, подходящий `autocomplete`, inline error рядом с формой. Кнопка отправки занимает всю ширину на узком экране и показывает pending state.

## Loading и ошибки

Skeleton повторяет структуру экрана и отключает shimmer при reduced motion. Ошибка не раскрывает технические детали или существование аккаунта.
